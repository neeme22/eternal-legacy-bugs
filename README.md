# Bugs de Eternal Legacy

Tablón de bugs del servidor. Se usa desde la pestaña **Bugs** del launcher.

- Para publicar un bug: **New issue** (o el botón *Publicar bug* del launcher) y rellena el formulario.
- Antes de publicar, busca en la lista por si ya está.

Estados:

| Etiqueta | Significa |
|---|---|
| Nuevo | Recién publicado, sin revisar |
| Visto | Revisado y confirmado |
| En curso | Se está arreglando |
| Arreglado | Resuelto (el bug se cierra) |
| No es bug | Funciona así a propósito, o no se ha podido repetir (el bug se cierra) |
